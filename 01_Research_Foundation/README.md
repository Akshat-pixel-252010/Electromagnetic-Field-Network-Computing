# Research Foundation

This folder contains the scientific foundations required to understand and develop EFNC.

Topics include:

* Information theory
* Electromagnetic fields
* Maxwell's equations
* Waves and interference
* Resonance
* Scattering theory
* Linear algebra
* Matrix multiplication
* Computation in physical systems

Purpose:

Build first-principles understanding before hardware development.

This folder answers:

What is information?

What is a field?

How can physical systems perform computation?

Why can matrix multiplication emerge from field interactions?
