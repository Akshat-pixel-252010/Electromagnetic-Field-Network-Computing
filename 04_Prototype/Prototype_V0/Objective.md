# Prototype V0

Goal:

Demonstrate that an electromagnetic field can be programmably modified using a voltage-controlled scatterer.

Hardware:

- RF source
- TX antenna
- RX antenna
- One tunable scatterer
- Varactor diode

Success Criteria:

Changing control voltage produces measurable and repeatable changes in received signal.

Failure Criteria:

No measurable effect.

Purpose:

Validate the fundamental assumption that field behavior can be controlled and programmed through tunable physical elements.
