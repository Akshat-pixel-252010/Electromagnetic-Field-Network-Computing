# Research Roadmap

This folder contains the planned development path of the EFNC project.

Purpose:

Break the project into manageable phases.

Research Phases:

Phase 0:
Foundation Building

Phase 1:
Programmable 2×2 Matrix Computation

Phase 2:
Trainable Matrix Engine

Phase 3:
Scaling and Characterization

Phase 4:
Resonator-Based Hybrid Networks

Phase 5:
Nonlinear Computation

Phase 6:
Neural Network Inference

Phase 7:
Field Accelerator Hardware

This roadmap may evolve as new discoveries are made.

The roadmap is intended as a guide rather than a fixed plan.
