# Research Lab Notebook

This folder acts as the project's scientific journal.

Purpose:

Record observations, ideas, experiments, failures, and lessons learned.

Rules:

- Document all major decisions.
- Record failed ideas.
- Record unexpected results.
- Record new hypotheses.
- Record future questions.

The goal is to preserve the complete thinking process behind the project.

Future researchers should be able to understand how the project evolved simply by reading this notebook.

Recommended Files:

- Daily_Logs.md
- Experiment_Logs.md
- Questions.md
- Lessons_Learned.md
