# Electromagnetic-Field-Network-Computing (EFNC)

## Overview

This repository documents a long-term research project exploring whether electromagnetic fields can be used as a computational medium for AI-related matrix operations.

Instead of performing computation through billions of transistor switching events, the project investigates whether programmable electromagnetic environments can naturally perform matrix transformations through field interactions governed by Maxwell's equations.

## Core Idea

Input Vector
→ Electromagnetic Encoding
→ Programmable Electromagnetic Environment
→ Field Interaction
→ Output Vector

where computation emerges directly from physical field dynamics.

## Long-Term Vision

Develop a field-based computing accelerator capable of performing matrix-vector operations with high parallelism and low energy consumption.
